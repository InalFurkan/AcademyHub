# Academy Hub: Student Information System

## Project Overview

**Academy Hub** is a web-based Student Information System (SIS) designed to streamline the management of student-related data and enhance the user experience for both students and administrators. The website is divided into two main sections:

- **Student Panel**: For enrolled students to access their educational details.
- **Admin Panel**: For administrators to manage and oversee student information, courses, schedules, and announcements.

Students can view their enrolled courses, grades, schedules, announcements, and personal profile information, while administrators have the ability to manage students, lectures, and announcements. They can add, edit, and delete entries as necessary, ensuring up-to-date and accurate data management.

The goal of **Academy Hub** is to simplify and improve upon traditional student information systems while maintaining the core functionalities. This project is built with a focus on accessibility, user-friendly design, and intuitive navigation to enhance the overall user experience.

## Features

### Student Panel:
- Log in with student credentials.
- View enrolled courses with corresponding exam scores.
- Check weekly schedule for courses.
- Access personal profile information and make updates.
- View announcements from administrators.

### Admin Panel:
- Log in with admin credentials.
- Manage student information, including contact details, grades, and course enrollments.
- Create, edit, and delete courses, schedules, and student profiles.
- Manage announcements visible to students.

## Technologies Used

### Frontend:
- HTML, CSS, JavaScript
- Plain HTML CSS for responsive design

### Backend:
- PHP for server-side scripting
- MySQL for database management

### Authentication:
- User authentication with login and session management (using PHP sessions).
